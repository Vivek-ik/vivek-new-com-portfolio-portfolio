Crafting Scalable Digital Experiences with Code and Creativity.

I'm a passionate full-stack web developer from Ahmedabad with 4+ years of experience building scalable, high-performance web apps. My core stack includes React, Next.js, TypeScript, NestJS, and MongoDB. I love solving real-world problems through clean, optimized code and modern UI/UX. My goal — building digital products that perform beautifully and scale seamlessly.

My Journey So Far

I began my journey in web development with a deep curiosity for how things work behind the scenes. From writing my first lines of HTML and CSS to building complex full-stack applications with React, Next.js, and Node.js, the excitement has only grown. Over the years, I’ve honed my skills in TypeScript, RESTful APIs, microservices, and scalable database design using both MongoDB and PostgreSQL.

Today, I specialize in building robust web applications with a strong focus on performance, maintainability, and scalability — integrating tools like Docker, Firebase, and RabbitMQ/Kafka when needed. I also enjoy exploring AI integrations such as OpenAI’s ChatGPT API to create intelligent user experiences.
