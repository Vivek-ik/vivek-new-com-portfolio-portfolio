Quiz Management System

A Scalable Platform for Conducting and Managing Employee Quizzes

Streamlining Assessments with Role-Based Access

The Quiz Management System allows organizations to create, assign, and evaluate quizzes seamlessly. With distinct roles Super Admin, Company Admin, and HR Admin it ensures granular control, security, and accountability across departments.

About the Project

The Quiz App is built to simplify skill assessment workflows within organizations. Each user role has dedicated permissions Super Admin oversees platform-wide operations, Company Admin manages quizzes for specific companies, and HR Admin handles user invitations and performance reports.

The platform includes authentication, quiz creation, timed tests, result analytics, and exportable reports. It supports multiple companies under one system, making it ideal for enterprises and training agencies.

Key Features

  • Role-based access (Super Admin, Company Admin, HR Admin)
  • Secure login and user authentication system
  • Dynamic quiz creation with multiple question types
  • Automated scoring and detailed analytics
  • Downloadable performance reports in CSV/PDF
  • Company-level segregation and management
  • Modern, responsive dashboard UI

Why It Matters

Efficient employee assessment is vital for growing organizations. This app empowers HR teams to create and manage quizzes quickly, track participation, and make data-driven hiring or training decisions.

“Assess smarter, not harder automate and track your organization’s learning journey.”

Tech Stack

  • Frontend: React.js, TypeScript
  • Backend: Node.js, Express.js
  • Database: MongoDB
  • Authentication: JWT + Bcrypt
  • Hosting: Railway (Backend), Netlify (Frontend)
